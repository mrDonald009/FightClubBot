# Тесты сценария добавления спортсмена

Этот каталог содержит сценарные (`flow`) тесты для диалога добавления спортсмена в `handlers.coach_handlers`.

## Карта модулей

- `basic_steps.py`  
  Базовые шаги сценария: медицина, возрастная группа, выбор типа абонемента, переходы между шагами.

- `validation_steps.py`  
  Валидации пользовательского ввода: ФИО, телефон, дата рождения, обработка некорректных значений.

- `calendar_and_shift.py`  
  Календарные ветки: выбор даты, навигация по календарю, shift-confirm/shift-cancel, обработка callback-data.

- `start_access.py`  
  Старт сценария и проверки доступа: кто может запускать сценарий, отмена, роль тренера/админа.

- `finalize_paths.py`  
  Финализация добавления: создание абонемента, расчёт дат для monthly/single, ошибки на финальном шаге.

## Агрегатор

Для совместимости и единой точки запуска используется агрегатор:

- `tests/test_add_athlete_flow.py`

Он импортирует тесты из модулей этого каталога.

## Как запускать

- Все flow-тесты проекта:
  - `pytest -m flow -q`

- Только сценарий добавления спортсмена:
  - `pytest tests/test_add_athlete_flow.py -q`

- Точечно по модулю:
  - `pytest tests/add_athlete_flow/calendar_and_shift.py -q`
